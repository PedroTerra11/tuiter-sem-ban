## 🧠 Sobre o Projeto
Este projeto foi criado em um momento em que o Twitter ficou indisponível.  
A ideia foi desenvolver rapidamente uma versão simplificada onde o usuário pudesse continuar postando e visualizando mensagens sem depender da plataforma original.

Não há moderação, bloqueios ou restrições: o objetivo foi apenas **continuar a conversa**, de forma divertida e espontânea.

## 🚀 Tecnologias Utilizadas

| Tecnologia | Função |
|-----------|--------|
| **JavaScript** | Lógica principal do programa |
| **Node.js** | Execução via console |
| **Git & GitHub** | Versionamento |

---

## 📌 Funcionalidades

| Função | Descrição |
|-------|-----------|
| Criar Post | Usuário publica mensagens |
| Ver Feed | Exibe todas as postagens na ordem criada |
| Timeline Simples | Feed sequencial, sem algoritmo |
| Sem Moderação | Nenhuma postagem é bloqueada ou removida |
