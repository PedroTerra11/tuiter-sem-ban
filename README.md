## 🧠 Sobre o Projeto
Este projeto foi criado em um momento em que o Twitter ficou indisponível.  
A ideia foi desenvolver rapidamente uma versão simplificada onde o usuário pudesse continuar postando e visualizando mensagens sem depender da plataforma original.

Não há moderação, bloqueios ou restrições: o objetivo foi apenas **continuar a conversa**, de forma divertida e espontânea.
